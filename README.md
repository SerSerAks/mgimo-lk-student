# Кабинет студента · концепт для МГИМО

Рабочий прототип личного кабинета студента — «цифрового деканата будущего» — для конкурса.
**Это концепт, а не официальный сервис МГИМО.** Все студенты, оценки, заявки и преподаватели вымышлены.

**Репозиторий:** https://github.com/SerSerAks/mgimo-lk-student
**Тестовые аккаунты:** логины — на странице входа («Тестовые аккаунты для жюри»), пароли — в комментарии к конкурсной работе.

## Что внутри

| Раздел | Что может студент |
|---|---|
| Вход и профиль | Вход по логину и паролю, смена пароля, профиль, история ступеней обучения |
| Сегодня | Пары дня с подсветкой текущей, переносы и замены, ближайшие мероприятия МГИМО |
| Расписание | По дням (по умолчанию сегодня) и неделей, чётные/нечётные недели |
| Успеваемость | Текущие баллы, экзамены, зачёты, долги, практика |
| Заявки и справки | 14 видов справок и заявлений, статус и история каждой заявки |
| Уведомления | О статусах заявок, переносах пар, сроках выбора руководителя |
| Научный руководитель | Выбор руководителя для курсовой / ВКР, заявка и ответ |
| Антиплагиат | Проверка работы (имитация) |
| Мой деканат | Кто за что отвечает, кабинеты и часы приёма |

### Как движутся заявки без деканата

Сотрудников в прототипе нет, поэтому за них «отвечает» система: заявка, поданная в кабинете, сама идёт **«Новая» → через 1 мин «В работе» → ещё через 2 мин «Готова, заберите в каб. 214»** — с уведомлением на каждом шаге. Заявка научному руководителю получает ответ примерно через минуту. Чтобы не ждать — кнопки «Ускорить (демо)». Код — [src/lib/demo-flow.ts](src/lib/demo-flow.ts).

## Реальные открытые данные МГИМО

- Расписание реальных групп — разовый импорт из открытого API РУЗ, **без ФИО и e-mail преподавателей** ([scripts/import-ruz.ts](scripts/import-ruz.ts)).
- Факультеты, направления и места приёма 2026 — из открытых PDF приёма ([docs/content/programs.csv](docs/content/programs.csv)).
- Анонсы мероприятий — с mgimo.ru, со ссылками на источник.

Кабинет в работе к системам МГИМО не обращается — только к собственной базе.

## Безопасность — коротко

- Пароли хранятся только в виде хеша argon2id; вход ограничен 5 попытками за 5 минут.
- Сессия — случайный токен в httpOnly-cookie, в базе хранится только его хеш.
- Каждый студент видит только своё: все правила — в одном файле [src/lib/access.ts](src/lib/access.ts). Чужая заявка по прямой ссылке даёт 404.
- Войти может только студент.
- Ключи и пароли — только в переменных окружения, не в коде и не в браузере.
- Автопроверка: `npm run test:access`.

## Стек

Next.js 15 (App Router, TypeScript), Tailwind CSS + shadcn/ui, PostgreSQL 16 + Prisma. Шрифт Montserrat (OFL), иконки Lucide (ISC).

## Запуск локально

```bash
cp .env.example .env      # заполнить пароль базы и APP_SECRET
docker compose up -d      # PostgreSQL на порту 5434
npm install
npx prisma migrate deploy
npm run db:seed           # тестовые данные; пароли → .demo-accounts.local.md
npm run dev -- -p 3001    # http://localhost:3001
```
