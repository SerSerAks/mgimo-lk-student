# 06. Заявка научному руководителю

**Дата:** 06.11.2026
**Промпт (дословно):** «обычно студенты сами договариваются с научным руководителем, поэтому надо придумать функционал где студент отправляет заявку науч руку а он ее принимает или отказывает.»

## Как ИИ развернул короткий промпт
ИИ предложил правила до кода и записал их в SPEC §12:
- кто выбирает (бакалавр с 3 курса, магистрант, аспирант без руководителя);
- одна активная заявка — чтобы не рассылали всем;
- лимит студентов у руководителя и «мест нет»;
- при согласии: закрепление, тема уходит на утверждение кафедре;
- новый тестовый аккаунт `student3`, чтобы жюри прошло сценарий само; для него импортировано настоящее расписание группы 3УП-01 из РУЗ.

## Что сделано
- Модели `SupervisorProfile` (должность, степень, интересы, лимит, уровни) и `SupervisorRequest`.
- Студент: список руководителей факультета с поиском по фамилии и интересам, «свободно N из M», заявка с темой и сообщением, отзыв, история.
- Руководитель: «Заявки студентов» — тема, сообщение, средняя оценка и долги студента; принять/отказать (отказ — с причиной).
- Уведомления обеим сторонам; лента уведомлений теперь есть и у сотрудников.
- На «Сегодня» у подходящих студентов — карточка «Выберите научного руководителя».
- Проверки доступа: 11 → 16.

## Проверено в браузере
student3 → заявка Тихонову (supervisor1) → у руководителя уведомление и заявка со средней 4,3 → «Принять» → у student3 руководитель, тема «на утверждении кафедры», уведомление «Руководитель согласился!».

## Ошибки ИИ и как исправили
| Что пошло не так | Как исправили |
|---|---|
| Prisma не увидел обратные связи — вставка не попала из-за выравнивания пробелов | Добавили поля вручную точечной правкой |
| Страница выбора упала с 500: dev-сервер держал старый Prisma Client после миграции | Перезапуск dev; правило в CLAUDE.md |
| «Принять» отвечало «Неизвестное решение»: кнопка shadcn не передаёт name/value | Решение — в скрытом поле по нажатию; правило в CLAUDE.md |
| Две проверки доступа сравнивали с фиксированным списком и упали после законного принятия студента | Переписали через правило: руководитель видит ровно закреплённых за ним и только текущие ступени |
