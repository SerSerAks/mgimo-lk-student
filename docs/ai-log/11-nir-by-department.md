# 11. НИР загружают кафедры

**Дата:** 06.11.2026
**Промпт (дословно):** «Нир загружают кафедры»

## Что сделано (SPEC §13)
- У кампании выбора руководителя появилось поле `departmentId`. Миграция `*_nir_by_department`.
- Кафедра: раздел «НИР» — загрузка НИР (уровень, курс, направление, сроки), прогресс, смена сроков, удаление без заявок.
- Приём и уведомления НИР — только преподавателям этой кафедры; аспиранты подбираются по кафедре, а не по факультету ФАНК.
- Деканат: из шаблона плана убрана НИР; в «Учебном плане» — раздел «НИР кафедр факультета» только для просмотра.
- Студент: вкладка «НИР · <кафедра>» и подпись, какая кафедра проводит.
- Демо: прежняя НИР деканата ФУП убрана; кафедра государственного управления загрузила НИР магистрантам 1 курса.
- Проверки доступа: 32 → 35.
