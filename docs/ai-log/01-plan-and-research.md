# 01. План работ и сбор данных МГИМО

**Дата:** 06.11.2026
**Инструмент:** Claude Code (десктоп-приложение, модель Claude Opus), субагент `web-fetch`, встроенный браузер Claude Code.

## Ключевые промпты (дословно)

1. Вставили полный текст задания конкурса и написали: «вот задача, дальше расписываем план работ».
2. «мы сначала продумываем сколько ролей: 1) студент: бакалавр, магистр, аспирант 2) деканат 3) научный руководитель 4) Выпускающая кафедра»
3. Передали файл `DESIGN.md` — заранее снятый с mgimo.ru визуальный язык (цвета, шрифты, сетка).
4. Выбор скруглений: «4–8px».
5. «у нас 16 дней»
6. «так сначала делаем наполнение потом занимаемся дизайном»
7. «Да, начинай»

## Что сделал ИИ

- `PLAN.md`: 8 этапов, стек, риски, таблица соответствия критериям конкурса.
- По промпту про роли: матрица доступа (кто что видит), сквозной сценарий «Выпускная работа» через 4 роли, 7 тестовых аккаунтов, пересчёт сроков с 8–10 до 10–12 дней.
- По дедлайну: календарь по дням, первый деплой на 3-й день (проверить доступность из РФ заранее), «страховочная сдача» 14.11.
- По смене порядка: этап «Дизайн» перенесён после функций, до него — базовые компоненты с токенами DESIGN.md.
- `docs/research/mgimo-open-data.md`: 14 факультетов и институтов, примеры кафедр, формат групп, две сетки пар, недели чёт/нечет, формат расписания из открытого API РУЗ.
- `CLAUDE.md` и `AGENTS.md` — правила проекта для ИИ-агентов.

## Ошибки ИИ и как исправили

| Что пошло не так | Как исправили |
|---|---|
| Субагент `web-fetch` получил с mgimo.ru пустые страницы-заглушки (сайт отдаёт контент только браузеру) | Переключились на встроенный браузер: страницы открылись, данные собраны |
| Через браузер нашли открытое API расписания РУЗ, но в ответе есть ФИО и e-mail преподавателей | Взяли только дисциплины, время, аудитории; правило «преподаватели вымышленные» записали в CLAUDE.md |
| PDF со шкалой оценок сайт отдаёт только как скачивание, ни субагент, ни браузер не прочитали | Пометили шкалу как «[подтвердить]», в прототипе — допущение до ручной проверки |
| ИИ сначала предложил скругления 0 «как на сайте» под вопросом, а не решением | Вынесли решение человеку, выбрали 4–8px |

## Что сделано вручную

- Выбор вуза, ролей, порядка работ, скруглений.
- Снятие DESIGN.md с сайта (отдельная сессия).
