# 14. Декан редактирует список должностей

**Дата:** 06.11.2026
**Промпт (дословно):** «над чтоб должности декан мог редактировать вот то что у нас в выборе надо мочь редактировать»

## Что сделано (SPEC §15)
- Таблица `FacultyPosition` — справочник должностей деканата факультета; пустой заполняется типовыми должностями. Миграция `*_faculty_positions`.
- Декан: блок «Должности деканата» — добавить, переименовать (с обновлением у сотрудников), удалить, ↑↓ порядок. Проверка на сервере: только декан, только свой факультет, без дублей.
- Подсказки во всех формах (создание сотрудника, правка анкеты, назначение по логину) берутся из справочника; одна общая `<datalist>` вместо трёх с одинаковыми id.
