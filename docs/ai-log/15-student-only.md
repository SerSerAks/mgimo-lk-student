## Что сделано
- Копия полной версии в `/Users/serseraks/lk-student`, свой git и своя база (порт 5434, `name: lkstudent`).
- Удалены экраны и действия сотрудников, иерархия аккаунтов, совмещение должностей, справочник должностей, массовая загрузка из Excel.
- Вход — только для студентов (`auth.ts`, `getCurrentUser`); `access.ts` — только правила «каждый видит своё».
- Схема упрощена, одна стартовая миграция `20261106000000_init`; у заявки флаг `autoFlow`.
- `src/lib/demo-flow.ts`: заявка из кабинета идёт «Новая → В работе (1 мин) → Готово (2 мин)» с уведомлениями; ответ руководителя через 1 мин. Кнопки «Ускорить (демо)» и «Получить ответ сейчас (демо)».
- Тестовые данные: сотрудники остались как справочные данные (дерево деканата, руководители); в файле паролей — только студенты.
