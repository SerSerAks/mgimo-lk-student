# Журнал работы с ИИ

Нужен для описания процесса на конкурс (критерий «Масштаб использования нейротехнологий»).

Одна запись = одна рабочая сессия или этап. Формат записи:

- **Этап и дата**
- **Инструмент** (Claude Code, модель, субагенты, браузер и т.д.)
- **Ключевые промпты** — дословно, как писали
- **Что сделал ИИ** — результат, файлы
- **Ошибки ИИ и как исправили** — самое ценное для жюри
- **Что сделано вручную**
- **Скриншоты** — путь в `docs/screenshots/`

Файлы: `NN-краткое-название.md`, по порядку.
