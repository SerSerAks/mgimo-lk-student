# 04. Первая обратная связь команды → правки

**Дата:** 06.11.2026
**Инструмент:** Claude Code, встроенный браузер.

## Промпт (голосовой, дословно по смыслу)

Команда зашла под `student1` на боевом сайте и надиктовала замечания:
- «Сегодня» непонятная: лучше показать всё расписание на сегодня и подсвечивать текущую/следующую пару по времени; блок «Изменения сегодня и завтра» странный — изменения показывать прямо в расписании (зачёркивать отменённые, перенесённые, сменённую аудиторию), а если изменения завтра — показать расписание на завтра;
- нужна подача заявок; «справка об обучении» и «выписка из приказа» — разные документы;
- в левой колонке — ближайшие мероприятия с сайта МГИМО: где, когда, коротко о чём;
- антиплагиат: ссылка на систему, мои справки, проверить работу, получить справку;
- успеваемость — удобной таблицей: экзамены и зачёты отдельно, текущие оценки, учебный процесс;
- практика у факультетов в разное время — сроки должны настраиваться по факультету и направлению.

## Как ИИ работал с промптом

1. Сначала записал правки в `docs/SPEC.md` (раздел 11) — чтобы требования жили в документе, а не только в чате.
2. Разложил на 9 шагов в плане, по каждому — проверка в браузере.

## Что сделано

| Правка | Решение |
|---|---|
| «Сегодня» | Всё расписание дня одним списком; «Идёт сейчас» / «Следующая · через N мин»; прошедшие приглушены; отмена/перенос/аудитория — зачёркиванием в строке; при изменениях завтра — расписание на завтра |
| Перенос | Пара видна и в исходный день (зачёркнута: «перенесена на сб, 17:30»), и в новый (старое время зачёркнуто) |
| Заявки | Каталог из 14 типов в 3 группах (справки, заявления, практика), форма с автозаполнением из профиля, шаг «Проверьте», трекер этапов, отмена пока «Новая». Валидация на сервере собирается из описания типа |
| Выписка из приказа | Отдельный тип с выбором приказа |
| Мероприятия | 18 анонсов с mgimo.ru: дата, время, место, кратко, ссылка. Левая колонка на компьютере, блок на «Сегодня» на телефоне |
| Антиплагиат | Ссылка на mgimo.antiplagiat.ru, список проверок с %, загрузка работы (файл не сохраняется), справка с пометкой «ОБРАЗЕЦ» и печатью в PDF |
| Успеваемость | Сводка (средняя, долги, зона риска) + вкладки «Текущие / Экзамены / Зачёты / Учебный процесс»; таблица на компьютере, карточки на телефоне. Часы дисциплин посчитаны из реального расписания |
| Практика | Модель `PracticePeriod` (факультет + необязательное направление + курс); у МО — летом после 3 курса, у МП — в феврале 3 курса, у англоязычной программы МЭО — свой срок. Деканат редактирует только свой факультет |
| Демо-переносы | Пересчитываются каждый день (cron), чтобы к 28.11 не устарели |

## Ошибки ИИ и как исправили

| Что пошло не так | Как исправили |
|---|---|
| Анонсы mgimo.ru и RSS отдают серверу заглушку защиты от ботов | ИИ отказался обходить защиту автоматически; анонсы сняты через обычный браузер в снимок `data/mgimo-events.json` (как расписание) |
| В тексте анонса — биография спикера | Брали только первый абзац (что, где, когда), имя спикера убрали из заголовка |
| Перенос пары «исчезал» из исходного дня — видно только в новом | Расписание выбирает пары и по новой, и по старой дате |
| Сброс демо-изменений терял исходное время окончания и корпус | Служебные данные для отката хранятся в заметке изменения, пользователю показывается только причина; проверено двойным запуском |
| `await` внутри выражения вне async-контекста | Вынесли в отдельную переменную |
| Загрузка файлов упёрлась бы в лимит 1 МБ для server actions | Лимит поднят до 11 МБ в next.config |
