# 08. Иерархия аккаунтов и массовая загрузка из Excel

**Дата:** 06.11.2026
**Промпт (дословно):** «логика создания аккаунтов такая: проректор создает на каждый деканат, деканат создает на каждую кафедру, деканат также создает на каждого студента (бакалавр и магстр), а кафедра создает учетку аспиранту… создание аккаунтов: для студентов и для аспирантов должно быть возможноть сделать массово. формирования логина и пароля: деканат загружает фио списком эксель, а логин сам формируется: Иванов Петр Владимирович: Ivanov_P_V» → после обрыва сессии: «Попробуй еще раз».

## Что сделано
- Новая роль «Проректор»; поле «кто создал аккаунт»; кафедра у аспиранта; флаг «одноразовый пароль».
- Логин из ФИО с транслитерацией: Ivanov_P_V, Shchukina_Yu_A, Saltykov-Shchedrin_M_E; совпадения — Ivanov_P_V2. Вход без учёта регистра.
- Пароль 12 символов без похожих букв, показывается один раз + файл для выдачи (CSV «;», UTF-8 с BOM — открывается в Excel). В базе только хеш.
- Первый вход — обязательная смена пароля (все страницы перенаправляют на смену).
- Экран «Аккаунты»: проректор — деканаты; деканат — студенты (по одному и списком) и кафедры; кафедра — аспиранты (по одному и списком) и преподаватели — они же научные руководители (подтверждено командой: «Научные руководители — это преподаватели кафедры, так что да они создают карточки преподавателей»).
- Массовая загрузка .xlsx/.csv: ФИО одной колонкой или «Фамилия/Имя/Отчество», колонка «Группа»; шаг «Проверьте» с ошибками по строкам; до 500 строк. Сервер перепроверяет всё при создании.
- Сброс пароля подчинённому аккаунту — новый одноразовый, старые входы завершаются.
- Проверки доступа: 20 → 25.
