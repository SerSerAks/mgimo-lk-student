## 2. Формат учебных групп [факт]

Источник: поиск групп РУЗ `https://ruz.mgimo.ru/api/search?term=…&type=group`

- Бакалавриат: `{курс}{код факультета}-{номер}` → `1МО-01`, `3МП-01`, `2МЖ-03`, `1УП-02`, `1МИЭП-05`.
- Магистратура: `{курс}Маг{код программы}-{номер}` → `1МагГУ-01`, `1МагБД-01`, `1МагБП-01`.
- Кроме академических групп есть **языковые группы и подгруппы**: у одной группы в одно время идут разные языки (японский, китайский, корейский). Это нужно учесть в расписании: студент видит только свою языковую подгруппу.

## 3. Расписание [факт]

Источник: https://mgimo.ru/study/schedule/ и открытое API РУЗ `https://ruz.mgimo.ru/api/schedule/group/{id}?start=YYYY.MM.DD&finish=YYYY.MM.DD&lng=1`

- Учёба 6 дней в неделю (пары в субботу есть).
- Недели **чётные / нечётные**, 1-я неделя осеннего семестра нечётная, начинается 1 сентября.
- Расписание «в режиме ежедневной онлайн-корректировки», то есть изменения частые. Это аргумент за заметные уведомления о переносах.
- Есть официальное мобильное приложение «МГИМО.Расписание», но только с расписанием.
- Два графика пар:

| Пара | МЭО, МП, МБ, ИМТУР | МО, ФУП, МЖ |
|---|---|---|
| 1 | 9:00–10:20 | 9:00–10:20 |
| 2 | 10:35–11:55 | 10:35–11:55 |
| 3 | 12:55–14:15 (после обеда) | 12:10–13:30 |
| обед | 11:55–12:55 | 13:30–14:30 |
| 4 | 14:30–15:50 | 14:30–15:50 |
| 5 | 16:00–17:20 | 16:00–17:20 |
| 6 | 17:30–18:50 | 17:30–18:50 |
| 7 | 19:00–20:20 | 19:00–20:20 |
| 8 | 20:30–21:50 | 20:30–21:50 |

- Поля одного занятия в API: дата, день недели, начало, конец, дисциплина, вид работы (`Лекция` / `семинар`), аудитория, корпус, подгруппа, поле замены (`replaces`), примечание.
- Корпуса: «Корпус МО», «Корпус МЭО», «Новый корпус», «Виртуальное» (дистант). Аудитории: номера (`3141`, `БЦ-08`) или залы (`зал 2`).
- Магистратура учится **вечером** (19:00–21:50), это видно по группе `1МагГУ-01`.
- Примеры дисциплин 1 курса МО: Введение в зарубежное регионоведение, История России, Всеобщая история, История международных отношений и внешней политики России, Экономическая теория, Культура работы с данными, Основы российской государственности, английский второй, японский первый.
- Примеры дисциплин 3 курса МП: Финансовое право, Криминология, Европейское право, Международное право, Уголовный процесс, Гражданский процесс, Адвокат в семейном праве, Военный перевод.

**Важно:** в ответе API есть ФИО и e-mail преподавателей. В прототип их **не переносим**: берём только дисциплины, время и аудитории, а преподавателей генерируем вымышленных.

## 4. Оценивание

- [факт] В МГИМО действует **академический рейтинг**; есть «Шкала соответствия оценок: пятибалльных — рейтинговых — ECTS» и памятка студенту. Источник: https://mgimo.ru/study/akadrating/
- [факт] У МГИМО уже есть система **«Электронный деканат»** (индивидуальный учёт результатов). Источник: та же страница. *Следствие: в названии прототипа лучше избегать точного совпадения, чтобы не путать с официальной системой.*
- [факт] Существует «мониторинг оценки качества преподавания» (студенты оценивают преподавание).
- [подтвердить] Точные диапазоны шкалы. PDF `shkala-ocenok.pdf` и `pamyatka-studentu-2022.pdf` сайт отдаёт только на скачивание, автоматически прочитать не удалось. **Нужно: открыть PDF вручную и прислать таблицу.** До этого в прототипе — 100-балльная шкала с переводом в пятибалльную и ECTS, диапазоны помечены как допущение.

## 6. ВКР и допуск

- [факт] Проверка на заимствования через систему «Антиплагиат» (`mgimo.antiplagiat.ru`). Источник: https://mgimo.ru/students/study/
- [подтвердить] Порядок выбора темы, сроки, предзащита. В прототипе используем типовой порядок: выбор темы → утверждение кафедрой → закрепление руководителя → главы с комментариями → антиплагиат → предзащита → отзыв руководителя → допуск к ГИА.

## 9. Карта университета (аудитории) [факт]

Проверено 09.11.2026 во встроенном браузере.

- Официальная карта: https://mgimo.ru/territory/map/ — поэтажные планы корпусов А, Б, В, Г, Нового корпуса, библиотеки и др.
- Поиск карты `https://mgimo.ru/territory/?q=<аудитория>` сам переводит на нужный этаж и подсвечивает аудиторию: `3153` → `?room=3153`, `507` (Новый корпус) → `?room=n507`, «зал 2» → `?room=zal_gl_1_2`.
- `robots.txt` раздел `/territory/` не закрывает.
- **Как используем:** только ссылка из окна пары («Найти на карте МГИМО»), открывается на сайте МГИМО. Планы и данные карты не копируем и не парсим. Для «Б/а» и дистанционных занятий ссылки нет.
