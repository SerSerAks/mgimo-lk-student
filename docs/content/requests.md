# Типы заявок и справок

> ДОПУЩЕНИЕ: перечень МГИМО в открытых источниках не найден (см. research, раздел 5). Набор типовой для вузов РФ. Сроки — допущение для прототипа.

Общие поля из профиля (только чтение): ФИО, уровень, факультет, курс, группа, форма обучения, основа обучения.

## Справки

| Код | Название | Доп. поля | Срок | Получение |
|---|---|---|---|---|
| `study_cert` | Справка об обучении | Куда предоставить (текст); кол-во экз. (1–5) | 2 раб. дня | в деканате / электронно |
| `military_cert` | Справка для военкомата | Наименование военкомата; кол-во экз. | 3 раб. дня | в деканате |
| `social_cert` | Справка для соцзащиты / пенсионного фонда | Куда предоставить; кол-во экз. | 3 раб. дня | в деканате / электронно |
| `visa_cert` | Справка для визы (на английском) | Страна; даты поездки | 5 раб. дней | в деканате |
| `academic_cert` | Академическая справка | Причина (перевод / отчисление / другое) | 10 раб. дней | в деканате |
| `session_call` | Справка-вызов на сессию | Место работы; период сессии | 3 раб. дня | электронно |
| `scholarship_cert` | Справка о размере стипендии | Период (месяцы) | 3 раб. дня | электронно |

## Заявления

| Код | Название | Доп. поля | Срок рассмотрения |
|---|---|---|---|
| `retake` | Запись на пересдачу | Дисциплина (из списка долгов); желаемая дата (из списка) | 3 раб. дня |
| `individual_schedule` | Индивидуальный график | Причина; период; файл-подтверждение | 10 раб. дней |
| `academic_leave` | Академический отпуск | Основание (медицинское / семейное / другое); период; файл | 10 раб. дней |
| `transfer` | Перевод на другую программу / форму | Куда; причина | 15 раб. дней |
| `financial_aid` | Материальная помощь | Основание; файл-подтверждение | 10 раб. дней |
| `name_change` | Смена фамилии в документах | Новая фамилия; файл | 5 раб. дней |

Файлы-подтверждения в прототипе — только загрузка образца; реальные документы не загружать (см. плашку в форме).
