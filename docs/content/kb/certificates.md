# Как заказать справку?

Заявки → Новая заявка → выберите тип справки. Данные из профиля подставятся сами, останется указать, куда предоставить, и количество экземпляров.

Сроки: справка об обучении — 2 рабочих дня, для военкомата и соцзащиты — 3, для визы — 5, академическая справка — 10.

Когда справка будет готова, придёт уведомление, а в карточке заявки появится, где её забрать или кнопка «Скачать PDF».
