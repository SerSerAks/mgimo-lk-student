# База правил для ИИ-помощника

Короткие статьи, по которым отвечает ИИ-помощник. Каждая статья — один вопрос.
Все правила — **ДОПУЩЕНИЕ для концепта**, не официальные правила МГИМО. Помощник всегда добавляет: «Уточните в деканате или в официальных документах вуза».

Формат: заголовок-вопрос, короткий ответ, шаги, какая заявка в кабинете поможет (код из `requests.md`).
