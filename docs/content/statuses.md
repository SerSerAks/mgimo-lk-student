# Статусы человеческим языком

## Заявка

| Статус | Бейдж | Текст студенту | Уведомление |
|---|---|---|---|
| Новая | серый | Заявка отправлена. Деканат возьмёт её в работу в течение рабочего дня. | — |
| Принята в работу | синий | Деканат готовит документ. Обычно это занимает {срок}. | «Заявку №{n} взяли в работу» |
| Нужны уточнения | жёлтый | Деканату нужно уточнение: «{комментарий}». Ответьте в карточке заявки. | «По заявке №{n} есть вопрос» |
| Готова | зелёный | Готово! {способ: «Заберите в каб. {N}, {часы}» / «Скачайте PDF ниже»}. | «Справка готова» |
| Выдана | серый, галочка | Документ выдан {дата}. | — |
| Отклонена | красный | Заявку отклонили: «{причина}». Можно подать заново. | «Заявку №{n} отклонили» |
| Отменена | серый | Вы отменили заявку {дата}. | — |

## Изменения расписания

| Тип | Бейдж | Текст |
|---|---|---|
| Перенос | ПЕРЕНОС (красный) | {Дисциплина} перенесена с {было} на {стало}, ауд. {ауд}. |
| Замена аудитории | АУДИТОРИЯ (cyan) | {Дисциплина} сегодня в ауд. {новая} вместо {старая}. |
| Замена преподавателя | ЗАМЕНА (cyan) | {Дисциплину} ведёт {преподаватель}. |
| Отмена | ОТМЕНА (красный) | {Дисциплина} {дата} не состоится. {причина}. |

## Глава ВКР

| Статус | Текст студенту |
|---|---|
| Черновик | Глава не отправлена руководителю. |
| На проверке | Руководитель получил главу {дата}. |
| Есть замечания | Руководитель оставил {N} замечаний. Исправьте и загрузите новую версию. |
| Принята | Глава принята {дата}. |
